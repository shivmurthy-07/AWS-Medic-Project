# MediConnect setup

Requirements: Node.js 20 or newer, npm, and an accessible MySQL database.

## Configure the API

From the repository root, copy `api/.env.example` to `api/.env` and set at least:

- `DATABASE_URL` to a MySQL connection URL.
- `JWT_SECRET` to a private random signing key.
- `PORT=5050` and `NODE_ENV=development`.
- `BACKEND_LOCAL_URL=http://localhost:5050/api/v1/auth/`.
- Email and Cloudinary variables if those integrations are needed.

Then run from the `api` directory:

```powershell
npm install
npx prisma generate
npx prisma db push
npm start
```

## Configure the frontend

In the repository root `.env`, select the local API:

```env
REACT_APP_USE_LOCAL_API=true
REACT_APP_API_BASE_URL_LOCAL=http://localhost:5050
```

Run the frontend from the repository root in a second terminal:

```powershell
npm install
npm start
```

Open `http://localhost:3000`. See [finaldoc.md](./finaldoc.md) for API routes, environment variables, limitations, and validation results.
